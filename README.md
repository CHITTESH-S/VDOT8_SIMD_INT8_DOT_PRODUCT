# VDOT8_SIMD_INT8_DOT_PRODUCT
VDOT.8 — A custom SIMD INT8 dot-product hardware accelerator designed in Verilog, targeting edge-AI inference on low-power embedded devices. Features a 3-stage pipeline architecture, full RTL-to-GDSII ASIC flow using OpenLane on SkyWater SKY130 PDK, multi-corner static timing analysis, and FPGA hardware validation on Xilinx Artix-7 for real-world verification.
